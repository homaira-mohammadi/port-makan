# Port Makan design

Full design system (colours, type, logo rules, map pins, spot card): https://claude.ai/artifact/KeokmZhAohg5AGoheLKPMJ

- `brand/port-makan-mark.svg`: main logo mark and favicon
- `brand/port-makan-app-icon.svg`: PWA and home-screen icon
- `brand/port-makan-mark-mono.svg`: one-colour mark
- `tokens.css`: CSS variables for light and dark themes. Import it once at the app root.
- `tokens.json`: source of the tokens

Fonts (Google Fonts):

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,700;12..96,800&family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap">
```
